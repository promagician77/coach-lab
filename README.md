# Youth Sports App · Go-to-Market Lab

A 90-day go-to-market strategy lab for a founder-led youth sports coaching app, built as a Vercel-deployable static site.

## What it shows

| Tab | Content |
|-----|---------|
| Overview | Market size ($2.1B), COPPA constraint, positioning, three-phase plan |
| Competitors | 5 verified competitors (TeamSnap, Spond, Heja, GameChanger, TeamLinkt) |
| ASO | iOS vs Google Play framework, keyword strategy, seasonal rotation |
| AI Agents | 6-agent architecture with approval gate, tooling, monthly cost (~$46) |
| 90-Day Plan | Week-by-week tasks across Foundation → Launch → Handoff |
| Model | Adjustable funnel model — all organic channels, zero ad spend |
| Metrics | 10 KPIs tracked weekly by the Analytics agent |
| Tests | 20 logic and data tests, all passing |

## Deploy

```bash
npm i -g vercel
vercel --prod
```

## Measured vs not measured

**Measured (from public sources):**
- Market size and CAGR (Market Intelo 2025)
- Competitor user counts, pricing, features (company sites, CBInsights, PR Newswire)
- ASO ranking factors and limits (Apple guidelines, App Radar, Gummicube)
- COPPA and Kids Category rules (Apple App Store Review Guidelines §1.3, §5.1.4)
- AI agent tooling costs (Make.com, Zapier, Anthropic pricing pages)

**Not measured (assumptions in the model):**
- ASO impressions and tap rates for this specific app
- Content click-through and install conversion rates
- League partnership response rates
- Webinar attendance and conversion rates
- Referral rates
- All model numbers are starting assumptions — replaced with real data at the week-8 checkpoint
